# Programação Orientada a Objetos em Java: construindo um sistema de gestão de funcionários.

1. Contextualização
Uma empresa de tecnologia deseja desenvolver um sistema para cadastrar, consultar e gerenciar os
dados de seus funcionários. A organização possui diferentes categorias de profissionais, como
funcionários administrativos e desenvolvedores de software, que compartilham algumas características,
mas também apresentam atribuições e formas de remuneração específicas.

Para solucionar esse problema, a equipe de desenvolvimento deverá criar um sistema utilizando a linguagem 
Java e os conceitos fundamentais da Programação Orientada a Objetos (POO). Durante o desenvolvimento, 
os estudantes deverão aplicar classes, atributos privados, encapsulamento, métodos getters e setters, 
construtores, herança, polimorfismo, sobrescrita e sobrecarga de métodos. A proposta permitirá compreender 
como a herança facilita o reaproveitamento de código e como o polimorfismo possibilita que diferentes 
tipos de funcionários apresentem comportamentos específicos por meio de uma estrutura comum.

2. Situação-problema
A empresa TechSolutions realiza o gerenciamento de seus funcionários por meio de planilhas eletrônicas.
Com o crescimento da organização, tornou-se necessário desenvolver um sistema que facilite o armazenamento
e a consulta das informações dos colaboradores.

A empresa possui dois tipos principais de funcionários:

- Funcionário administrativo: possui salário-base e recebe um adicional de produtividade.
- Desenvolvedor de software: possui salário-base e recebe um adicional de acordo com o nível de experiência.
A equipe de desenvolvimento deverá criar uma aplicação Java capaz de representar esses profissionais, permitindo
cadastrar seus dados, consultar informações e calcular a remuneração de cada funcionário.

O sistema deverá atender aos seguintes requisitos:
1. Todo funcionário possui nome, CPF, matrícula e salário-base.
2. Os atributos das classes devem ser privados, impedindo o acesso direto aos dados externos.
3. A consulta e a alteração dos atributos devem ocorrer por meio de métodos apropriados.
4. Cada tipo de funcionário deverá possuir características específicas.
5. O cálculo da remuneração deverá apresentar comportamentos diferentes conforme o tipo de funcionário.
6. O sistema deverá permitir criar objetos utilizando diferentes construtores.
7. Deverá ser possível utilizar uma referência da classe pai para armazenar objetos das classes filhas.
8. O sistema deverá permitir exibir as informações de cada funcionário de maneira específica.

Desafio: como desenvolver um sistema em Java que permita gerenciar diferentes categorias de funcionários, reutilizando código e aplicando os principais conceitos da Programação Orientada a Objetos?
